# SS-THS: Self-Sustaining Thermal Harvesting System

This project simulates a vertical stack for energy harvesting from high-load IC chips.

## Key Features
* **Layered Architecture:** Silicon IC -> TEG -> Nanowire Pump -> Rad Skin.
* **PMU Simulation:** Realistic boost conversion from raw mV to 4.2V.
* **3D Schematic:** Interactive MATLAB R2016a UI with component mapping.

## How to Run
1. Open `SelfSustainingCooling.m` in MATLAB.
2. Press Run.
3. Use the slider to simulate heat load.
